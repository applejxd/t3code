T3 Code — applejxd fork

Fork of pingdotgg/t3code that keeps Pi (pi-background bg_run) jobs alive. Source and releases: github.com/applejxd/t3code.

Install the CLI

macOS / Linux:

curl -fsSL https://applejxd.github.io/t3code/install.sh | sh

Windows (PowerShell):

irm https://applejxd.github.io/t3code/install.ps1 | iex

The scripts download the latest stable release of the fork from GitHub Releases.
